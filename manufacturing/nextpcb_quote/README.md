# old quote files

these files describe the august 2026 monolithic board. they are retained
as a quote record and do not match the current split main boards.

do not use their BOM, placement files or zip for an order. in particular,
they predate the Mu Ultra power changes and the corrected 0.4 mm TPD1S514
footprint. fresh per-board packages must come from the current schematics
and boards after routing and fabrication checks.
