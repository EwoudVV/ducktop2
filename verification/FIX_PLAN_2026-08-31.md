## Refined architecture (post-investigation, 2026-08-31 — supersedes drafts above)

**R1 — Cable geometry law (settles D2).** Physics of horizontal bottom-contact FFC: free cable extends from the **front (contact) face**; a single straight strip can only join two connectors whose **mouths face each other**, and that configuration requires **one z-fold in the gap between the contact rows** (both insertion slides happen away from the fold). Equal rotations = mouths same direction = physically impossible for in-line coplanar connectors (one end always backs into the other connector). Empirical mapping rule (validated twice: keyboard contract + pad world-coords): **opposite rotations ⇔ reversed mapping; equal ⇔ straight.**
**Decision: all three cables get opposite rotations (mouths facing across each seam) + `CABLE_TRANSFORM = "reversed"` in the contract** (far-side map = mirror of near-side). Rotation targets: FPC101 90→**270**, FPC102 270→**90**, FPC103 90→**270**, FPC104 270→**90**, FPC105 180→**0**, FPC106 0→**180**. Fold bands (no footprints; cable flies over copper): seam-70 x∈[contactsA+0.5, contactsB−0.5], seam-300 mirrored, seam-y0 on the BMS between its y60 edge and FPC106 contacts. Anchor adjustments to give ≥4.5 mm fold gaps: FPC101 → x≈61.5, FPC104 → x≈306.5, FPC106 → y≈52 (verify part-free at build).

**R2 — Charge-source architecture (settles A7).** `add_pd_selector` (U14+Q15–Q18) was written pre-split with both USB-C ports on one sheet; post-split its V2 (`PD2_VBUS_GATED`) is stranded. **Remove U14/Q15/Q16/Q17/Q18 + window dividers from the left** (redundant: U720 TPS26630 blocks backflow + U15 re-validates 13.1–17.1 V); left exports `USB_PD_SELECTED` = U720 OUT (hold-up C2146 stays). **Center gains U15B (LTC4418IUF) + Q17/Q18 (PD2 back-to-back pair) + Q24b (second series FET on AUX — also fixes C2)**: U15B.V1 = PD2 path (window 13.1–17.1 V), U15B.V2 = AUX path (window per AUX spec), U15B.OUT → U15.V2 (window retuned to accept both ≈6.3–22.8 V), U15.V1 = USB_PD_SELECTED (unchanged), U15.OUT = VBUS_COMBINED. Priority: PD1 > PD2 > AUX. All LTC4418 dividers recomputed from the datasheet thresholds at implementation time (also resolves C3's unverified 1.235 V ref).

**R3 — Hub port mapping (supersedes the frozen spec's "DS4").** J11's data = `HUB_DS1_DP/DM` crossing FPC-2 pins 34/35 and FPC-1 pins 40/41 (pass-through on the center — contract is already consistent; the frozen spec's DS4 was superseded by the implementation). The left hub's DS4 (DP/DM + PRT_CTL4) is genuinely unused → no-connect flags (fixes the left ERC isolated-label trio). J12's U1760 (TPS2553) EN ← tied to its VIN per datasheet (always-on, current-limited) — fixes the right ERC genuine error. J12's data pins: verify charge-only (no host nets) at implementation.

**R4 — Net-name normalization (refines D1).** Netlists carry sheet-prefixed names for label nets but **unprefixed** names for power-symbol nets (GND etc.). New post-build pass `normalize_board_nets`: for every board net name, if it exactly matches a netlist name → keep; else if its basename uniquely matches a netlist name → rewrite to the netlist's full name; else fail loudly. Run on all four boards after connector-net assignment. Result: board nets == schematic nets (fixes B4 parity class), netclass patterns (prefixed) match (B2), contract resolution trivial.

**R5 — BMS ground (confirms D3 with netlist evidence).** BMS `GND` (power symbol) currently floats via cable pins 9–30; `FG_VSS` (Q704 post-FET return) crosses on pin 7 only; the center's `CENTER_RENAME` bonds pre-FET pack− into system ground (the protector bypass). **New FPC-3 map: pins 1–12 PACK_POS_FUSED, 13 PACK_FAULT_N, 14 PACK_RETRY_PULSE, 15 MCU_3V3, 16–30 FG_VSS (15 return pins ≈ 6 A at 0.4 A/pin derate).** BMS ground symbol net becomes FG_VSS (bonded locally to the protector output); U11 LTC4368 GND and the BMS logic reference the protected return (required for correct breaker behavior). Gauge shunt RS1 on the center stays between GND and /FG_VSS — the return current path becomes GND → RS1 → /FG_VSS → cable → BMS post-FET return.

## Key architectural decisions (made once, applied everywhere)


**D1 — Net-name unification (fixes A1, B2, part of B4/B10).**
All four boards will carry **schematic-prefixed net names** (the center already does; the daughterboards' boards will be rebuilt from their schematics so pad nets match the netlists). `fpc_contract.py` stays bare-name; a new resolver maps each bare contract name to the per-board actual net name (basename match against the board's net inventory; 0 or >1 matches = hard failure). `CENTER_RENAME` is deleted (superseded by D3).
- *Why not bare-everywhere:* center board↔center schematic parity would regress (B13), and the fabrication gate's schematic-parity check compares full names.

**D2 — Cable transforms in the contract (fixes A2/A3 class permanently).**
`fpc_contract.py` gains an explicit per-cable `CABLE_TRANSFORM`: `"straight"` (pin N ↔ pin N) or `"reversed"` (pin N ↔ N_max+1−N), and per-connector required rotations. The generator asserts: measured footprint rotations on the rebuilt boards match the transform (equal ⇔ straight, 180°-apart ⇔ reversed). Whichever fold geometry the mechanical docs dictate, the contract encodes it and a gate enforces it — the reversal bug class cannot silently return.
- Fold-side decision per seam is made from `BOARD_SPLIT_SPEC_2026-08-28.md` + free space on the rebuilt boards; documented in the contract file.

**D3 — BMS return architecture (fixes A5/A6, enables cell protection).**
The pack **negative never crosses FPC-3**. The BMS's protected return (FG_VSS, post-FET) *is* the BMS ground reference; FPC-3's return pins carry FG_VSS on the BMS side and GND on the center side (same conductor, name changes at the connector — resolved per-board by D1's resolver, no `CENTER_RENAME`). Protector trip → load loses its return → correct low-side protection behavior; the gauge shunt stays in the load path. Verified against the bms schematic before implementation (Plan P5).

**D4 — FPC power re-pinning (fixes A8/A9).** At Hirose 0.5 A/pin derated to 0.4 A/pin for cable-length margin:
- FPC-3 (FH12-30S): pins 1–12 `PACK_POS_FUSED` (4.8 A), 13 `PACK_FAULT_N`, 14 `PACK_RETRY_PULSE`, 15 `FG_VSS`, 16 `MCU_3V3`, 17–30 `GND` (5.6 A return). Worst cases covered: charge ≈4.4 A; discharge = system load ≤ LTC4368 breaker 4.545 A.
- FPC-1 (FH41-68S): VSYS ×6 (2.4 A), PD1_VBUS_RAW ×7 (2.8 A), USB_PD_SELECTED ×7 (2.8 A), AUX_DC_RAW ×6 (2.4 A) + **source-side fuse added on the left board** (fixes the unfused-cable-segment half of A9), USB_PORT_5V ×2, SYS_3V3 ×2, MCU_3V3 ×2; USB3/USB2 pairs keep GND flanks; remaining pins GND.
- FPC-2 (FH41-68S): SYS_5V ×5 (2.0 A), **PD2_VBUS_GATED ×7 (2.8 A — new net, fixes A7)**, PD2_VBUS_RAW ×2 (sensing only), USB_PORT_5V ×2, SYS_3V3 ×2, PCIE_3V3 ×2, MCU_3V3 ×2; TMDS/GBE pairs keep GND flanks.
- Charger input ceiling stays IINDPM = 3.00 A (within all new pin budgets).

**D5 — Connector placement & orientation (fixes A2/A3, B14 seam clearances).**
Connectors are rotated/anchored by the connector resolver per D2 with: front (contact) side facing the seam, pads ≥0.5 mm from Edge.Cuts, courtyards inside the outline, a documented z-fold keepout band on the chosen fold side (no parts, no copper in the band), connector **body extents** (not just pads) added to every keepout (fixes the ten buried passives, U51/U12), and explicit anchor-correction entries for C750, J41, J420/J421, U51, U12, J422/SW900, U913, C703.
